# gps-tuiles

Construction hebdomadaire des tuiles de routage [Valhalla](https://github.com/valhalla/valhalla)
pour la France, l'Espagne, le Portugal, la Belgique, le Luxembourg, la Suisse et Andorre,
utilisées par le GPS d'OnBouge (https://gps.onbouge.eu).

- Source : extraits par pays de [Geofabrik](https://download.geofabrik.de/europe.html), fusionnés en un seul fichier.
- Chaque construction est vérifiée par de vrais calculs d'itinéraire avant d'être publiée.
- Résultat : une Release (archive découpée en morceaux + `SHA256SUMS`), que le serveur télécharge.
